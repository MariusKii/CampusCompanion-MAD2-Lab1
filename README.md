## Project Description

CampusCompanion is a basic native iOS application developed using Swift, UIKit, and Storyboard. The project demonstrates Storyboard interface design, Auto Layout constraints, IBOutlet connections, and IBAction functionality.

## Features

- Campus Companion welcome screen
- Title and subtitle labels
- UIImageView
- Get Started button
- Dynamic subtitle update using IBAction
- Auto Layout support for different iPhone screen sizes

## Technologies Used

- Swift
- UIKit
- Xcode
- Storyboard
- iOS Simulator

## How to Run

1. Clone this repository to a Mac with Xcode installed.
2. Open `CampusCompanion.xcodeproj` in Xcode.
3. Select an iPhone Simulator as the run destination.
4. Press **Run** or use `Cmd + R`.
5. Tap **Get Started** to update the welcome subtitle.
